sidewalk

Chrome Firefox GitHub

Walk what your agent built, in a side panel.

The agent writes the walk through an MCP. Your answers come back to it as data.

Your agent builds something, then writes the checklist for you to walk. Cards open in a Chrome side panel next to the live site. Each one says where to go and what to look for. Answer it, and the answer goes back to the agent with a screenshot and your exact words.

What a card can do

Press Go. It opens the page and points at the thing to check.

Tick each step as it works. If one breaks, say where.

Every answer has an Undo.

Secrets stay out of the chat and out of the screenshots.

Ask a question. The answer lands on the card.

Install

Node 22 and Chrome. Two lines:

npx -y sidewalk-walkd serve
claude mcp add --scope user sidewalk -- npx -y sidewalk-mcp

Or one line, which does both and says what is left:

curl -fsSL https://sidewalk.sh/install | sh

The extension is sidewalk on the Chrome Web Store, and the same add-on is on Firefox. The README has the steps for a build from a checkout.

Limits

The daemon listens on loopback only. It answers only a caller that has the token it makes when it starts. More in the README.
